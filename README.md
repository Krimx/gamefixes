## ⚠️ Spoilers!

Everything below contains spoilers for the mod. If you like discovering things on your own, do not read past this point.

## Added

* More golden crops
* Villager research system
* New mace right-click swing attack
* Use Echo Shards in an anvil to remove the enchantment penalty
* Drop concrete powder into water to instantly convert it
* Tridents can now be found in aquatic archaeology
* Elytra-Chestplate, for those who got the Zenith in Terraria

## Removed

* Golden carrot villager trade
* Mending villager trade
* Furnace functionality
  The furnace block is still in the game for those who want it, but it no longer functions.

## Changed

* Stair recipe: 3 blocks now craft 4 stairs
* Blast furnace crafting recipe
* Trial Chamber loot system: the Mace can be obtained much more easily
* Nerfed Mace
* Buffed Mace enchantments
